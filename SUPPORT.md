# Soporte

## ¿Tu perfil aparece mal, o no aparece?

El ranking se regenera cada semana desde la API pública de GitHub, así que lo que
cambies en tu perfil se refleja en la siguiente corrida. Antes de reportar algo,
revisa [cómo se calcula el score](https://top-coders-chi.vercel.app/metodo) — ahí
están los límites conocidos, incluido el más común: el país sale del campo
`location` de tu perfil, que es texto libre.

## Reportar un problema

Abre un issue: https://github.com/harold18m/top-coders/issues

Es el canal preferido, porque la respuesta queda pública para quien tenga la misma
duda.

## Contacto directo

Para lo que no corresponda a un issue (privacidad, retirar tu perfil del ranking,
uso de los datos): harold@dropout.cl
